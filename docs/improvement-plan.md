## 1. UX 개선

### 1-1. 스트리밍 답변 ⭐ 최우선

**현재:** AI 답변이 전체 생성이 끝난 뒤 한 번에 표시 (5~15초 대기)
**개선:** 글자가 한 글자씩 실시간으로 나옴 (ChatGPT 방식)

**구현 방향:**
- `MLXChatEngine`의 `ChatSession.respond` 대신 스트리밍 API 사용
- `AsyncSequence`로 토큰을 받아서 실시간으로 `MessageBubbleView` 반영
- `ChatView`에서 메시지 content를 점진적으로 업데이트

**영향 범위:** `ChatEngine.swift`, `ChatView.swift`, `MessageBubbleView.swift`, `AppState.swift`

### 1-2. 온보딩 화면

**현재:** 앱 실행 → 메뉴바 아이콘만 보임 → 뭘 해야 하는지 모름
**개선:** Welcome 화면 → 단계별 권한 안내 → 단축키 설정 → 완료

**단계:**
1. "접근성 권한 허용" (왜 필요한지 설명)
2. "화면 녹화 권한 허용" (스크린샷용)
3. "단축키 확인/설정"
4. "준비 완료! ⌥Space로 시작하세요"

**구현 방향:** `OnboardingView.swift` 신규, `UserDefaults`로 최초 실행 여부 저장

### 1-3. 캡처 성공 피드백

**현재:** Remember 클릭 → 팝업 닫힘 (저장됐는지 불명확)
**개선:** 메뉴바 아이콘에 체크마크 애니메이션 또는 작은 토스트 "✓ Remembered"

**구현 방향:** `CapturePopupView.swift`의 `save()` 후 `NSStatusBarButton` 이미지 변경 → 1초 후 원복

### 1-4. 검색 결과 하이라이팅

**현재:** [1], [2] 소스 참조 → 소스를 열어야 원문 확인
**개선:** [1] 클릭 시 인라인으로 소스 미리보기 펼침, 또는 호버 시 팝오버

**구현 방향:** `MessageBubbleView`에서 [N] 패턴 감지 → 클릭 가능 링크로 변환

### 1-5. 대화 제목 자동 생성 개선

**현재:** 첫 질문의 앞 40자를 그대로 제목으로 사용
**개선:** AI가 대화 주제를 2~4단어로 요약

**구현 방향:** `AppState.generateResponse`에서 첫 응답 생성 시 별도 짧은 프롬프트로 제목 생성

## 2. 검색 품질 개선

### 2-1. 유사도 임계값 ⭐ 간단하면서 효과 큼

**현재:** `VectorSearchEngine.search`가 topN 결과를 유사도 무관하게 반환
**개선:** 유사도 0.3 이하 결과 제외

**구현:** `VectorSearchEngine.swift`에 `minScore` 파라미터 추가

```swift
func search(query: String, topN: Int = 20, minScore: Float = 0.3) async throws -> [SearchResult]
```

### 2-2. 하이브리드 검색 (벡터 + 키워드)

**현재:** 벡터 검색만 사용
**개선:** SQLite FTS5 키워드 검색 + 벡터 검색 결과를 RRF로 통합

**효과:** "GRDB", "OAuth" 같은 정확한 키워드 검색 시 정확도 대폭 향상

**구현 방향:**
1. FTS5 가상 테이블 마이그레이션 추가
2. `KeywordSearchEngine` 구현
3. `HybridSearchEngine`에서 벡터 + 키워드 결과를 RRF(Reciprocal Rank Fusion)로 합산

### 2-3. 대화 컨텍스트 활용 검색

**현재:** 매 질문마다 독립적으로 벡터 검색 (후속 질문 맥락 무시)
**개선:** 이전 대화를 참고해서 검색 쿼리 보강

**예시:**
- 질문: "거기서 민수님이 뭐라고 했어?"
- 현재 검색: "민수님이 뭐라고" (맥락 없음)
- 개선 검색: "지난주 회의 API 명세 민수님 발언" (이전 대화 참조)

**구현 방향:** `MLXChatEngine.send`에서 이전 대화 컨텍스트를 검색 쿼리에 보강하는 로직 추가

## 3. 안정성/성능 개선

### 3-1. 모델 로딩 상태 UI

**현재:** MLX 모델 다운로드/로딩 중 진행 상황 미표시
**개선:** Settings 또는 메뉴바에 상태 표시

```
"AI 모델 다운로드 중... 2.3GB / 3.1GB (74%)"
"AI 모델 로딩 중..."
"AI Ready ✓"
```

**구현 방향:** `AppState`에 `modelStatus` 프로퍼티 추가, `MenuBarView`에서 표시

### 3-2. 메모리 관리

**현재:** `ChatSession` 대화가 길어지면 메모리 무한 증가
**개선:**
- 대화 이력이 N턴을 넘으면 오래된 턴 제거
- 일정 시간 미사용 시 모델 언로드
- 메모리 사용량 모니터링

**구현 방향:** `MLXChatEngine`에 세션 관리 로직 추가

### 3-3. 에러 복구 개선

**현재:** "오류가 발생했습니다: ..." 단순 메시지만 표시
**개선:**
- 컨텍스트 초과: "대화가 너무 길어졌습니다. 새 채팅을 시작할까요?" + 버튼
- 모델 미로드: "AI 모델을 준비 중입니다 (약 1분)"
- 자동 재시도 버튼

**구현 방향:** `ChatView`에서 에러 타입별 분기 처리

### 3-4. 대용량 데이터 최적화

**현재:** `VectorSearchEngine`이 모든 임베딩을 매번 DB에서 읽어서 brute-force 비교
**개선 (수만 건 이상 시):**
- 벡터 캐시 유지 (매번 DB 읽기 방지)
- HNSW 인덱스 도입

**시급도:** 낮음 — 수천 건까지는 현재 방식으로 충분

## 4. 기능 확장

### 4-1. BYOM (Bring Your Own Model)

사용자가 자신의 API 키를 입력해서 더 좋은 AI 사용.

```
Settings > AI Model
├── 로컬 AI (Qwen3-4B)     ← 기본값, 무료
├── OpenAI API             ← 사용자 키 입력
├── Anthropic API          ← 사용자 키 입력
└── Ollama (로컬)          ← 로컬 서버 주소
```

**구현 방향:**
- `ChatEngineProtocol`에 OpenAI/Anthropic 구현체 추가
- Settings에 모델 선택 UI + API 키 입력 (Keychain 저장)

### 4-2. 내보내기

```
Memories > 우클릭 > Export
├── Markdown 파일
├── JSON
└── Obsidian 노트 (frontmatter 포함)
```

### 4-3. URL 재방문

**현재:** 캡처 시 URL 저장하지만 소스 상세에서 다시 열 수 없음
**개선:** `SourceDetailView`에 "Open URL" 버튼 추가

**구현:** 간단 — `NSWorkspace.shared.open(url)` 한 줄

### 4-4. 태그/주제 기반 탐색

**현재:** Topics가 생성되지만 UI에서 활용 안 됨
**개선:** Memories 사이드바에 Topics 섹션 추가

```
Topics
├── API (12)
├── 인증 (8)
├── SwiftUI (5)
└── 회의 (3)
```

**구현 방향:** Topics를 JSON 배열에서 파싱 → 집계 → 사이드바 필터 UI
