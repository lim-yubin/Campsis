## 1. 제품 포지셔닝

### 핵심 문제

> 사람들은 하루에 수백 개의 정보를 접하지만, 며칠 뒤 "그거 어디서 봤더라?"를 반복한다.

### 경쟁 환경

| 경쟁 서비스 | 가격 | 방식 | Campsis 대비 약점 |
|-----------|------|------|-----------------|
| **Rewind** | $25/월 | 화면 24시간 녹화, 클라우드 | 비쌈, 프라이버시 우려 |
| **Limitless** | $20/월 | 웨어러블 + 클라우드 AI | 하드웨어 필요, 데이터 서버 전송 |
| **Mem X** | $15/월 | 클라우드 노트 + AI | 수동 입력, 클라우드 의존 |
| **Notion AI** | $10/월 | 기존 노트에 AI 추가 | 캡처 기능 없음, 클라우드 |
| **Apple Notes** | 무료 | 기본 메모 | AI 검색 없음, 수동 정리 |

### Campsis 차별점

1. **제로 마찰 캡처** — 단축키 하나로 보고 있는 것을 즉시 기억 (의도적 기억)
2. **100% 로컬** — 데이터가 기기를 절대 떠나지 않음 (경쟁사 대비 유일)
3. **서버 비용 0** — 사용자당 한계비용이 거의 없음 (스케일 시 수익성 유리)

### 타겟 사용자

**1순위: Mac 개발자/디자이너**
- 하루 종일 Chrome, Slack, IDE, Figma 사이를 오감
- "어디서 봤는데..." 가 일상
- 프라이버시에 민감 (코드, 사내 정보)
- AI 제품에 거부감 없음

**2순위: 지식 노동자 (PM, 컨설턴트, 리서처)**
- 문서, 회의, 리서치 자료가 많음
- Notion/메모 정리에 지침
- "내가 분명 정리했는데 어디에..."

**3순위: 학생/대학원생**
- 논문, 강의 자료, 참고 자료 관리
- 예산 제한적 → 무료 티어 중요

## 2. 비즈니스 모델

### 가격 구조

#### Campsis Free (₩0)
- 로컬 캡처 + 로컬 AI (Qwen3-4B)
- 대화형 검색
- Quick Note + 파일 업로드
- 무제한 저장

#### Campsis Pro (₩9,900/월, 연간 ₩7,900/월)
- Free의 모든 기능
- 클라우드 AI 선택 (Claude 4 / GPT-4o / Gemini)
- 고급 내보내기 (Obsidian, Markdown)
- 우선 이메일 지원

#### Campsis Pro+ (₩19,900/월, 연간 ₩15,900/월)
- Pro의 모든 기능
- Mac ↔ iPhone 동기화
- 다중 Mac 동기화
- 팀 공유 (선택한 기억을 팀원과 공유)
- API 접근

### 가격 책정 근거

경쟁사 대비 절반 이하 가격. 무료 티어가 핵심 기능 완비.
"유료는 더 편한 경험" 포지셔닝.

### 무료 티어에 제한을 두지 않는 이유

1. 로컬 앱이라 서버 비용이 0 → 무료 사용자가 많아도 손해 아님
2. 기억 앱은 데이터가 쌓여야 가치 → 제한하면 가치를 느끼기 전에 이탈
3. 충분히 써봐야 "더 좋은 AI 답변"의 차이를 체감

## 3. 유료 전환 핵심 기능

### 기능 1: 클라우드 AI (Pro의 핵심)

**구조:**
- 질문 → 벡터 검색 → 관련 기억 선별 (여기까지 100% 로컬)
- 선별된 기억 조각만 Campsis Proxy 서버 → Claude 4 전달 (Pro만)
- 전체 DB가 아닌 관련 조각 5~10개만 전송
- E2E 암호화

**비용 구조:**
- Claude 4 Sonnet 기준: 사용자당 월 ~₩1,200
- 구독료 ₩9,900 - API ₩1,200 = 마진 ₩8,700 (88%)

### 기능 2: 기기 간 동기화 (Pro+의 핵심)

**동기화 대상:**
- 메타데이터 (앱, 제목, 날짜, 요약, 주제)
- 임베딩 벡터
- 암호화된 원본 텍스트

**동기화하지 않는 것:**
- 스크린샷 원본 (용량 + 프라이버시)
- 파일 원본

**방식:** iCloud CloudKit
- 사용자의 iCloud 저장소 사용
- Campsis 서버를 안 거침
- Apple E2E 암호화 적용
- 비용 거의 0

### 자동 캡처 — 제외 결정

프라이버시 메시지와 충돌하고, Rewind와 같은 포지션이 되며, 리소스/데이터 품질 문제.
"의도적 기억"이 Campsis의 차별점.
