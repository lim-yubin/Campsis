## 1. 제품 포지셔닝

### 핵심 문제

> 사람들은 하루에 수백 개의 정보를 접하지만, 며칠 뒤 "그거 어디서 봤더라?"를 반복한다.

### 경쟁 환경

| 경쟁 서비스 | 가격 | 방식 | Campsis 대비 약점 |
|-----------|------|------|-----------------|
| **Rewind** | $25/월 | 화면 24시간 녹화, 클라우드 | 비쌈, 프라이버시 우려 |
| **Limitless** | $20/월 | 웨어러블 + 클라우드 AI | 하드웨어 필요, 데이터 서버 전송 |
| **Mem X** | $15/월 | 클라우드 노트 + AI | 수동 입력, 클라우드 의존 |
| **Notion AI** | $10/월 | 기존 노트에 AI 추가 | 캡처 기능 없음, 클라우드 |
| **Apple Notes** | 무료 | 기본 메모 | AI 검색 없음, 수동 정리 |

### Campsis 차별점

1. **제로 마찰 캡처** — 단축키 하나로 보고 있는 것을 즉시 기억 (의도적 기억)
2. **로컬 우선(local-first)** — 캡처 · 임베딩 · 검색은 100% 기기에서. 원본 데이터는 기기에 남는다.
3. **하이브리드 AI** — 답변 생성만 선택적으로 클라우드(GPT-5.6 Luna) 사용. 전체 DB가 아닌 **선별된 기억 조각만** 전송.

> 갱신(2026-08-31): 로컬 생성 모델(Qwen3-4B)이 사용자 하드웨어를 과도하게 쓰고 품질도 아쉬워,
> **생성은 클라우드(Luna), 임베딩·검색은 로컬(bge-m3)** 하이브리드로 전환. "100% 로컬 / 서버 비용 0"
> 전제는 BYOK 플랜에만 유효하며, Free/Pro는 프록시 서버 비용이 발생한다. 상세는 `monetization-architecture.md` 참고.

### 타겟 사용자

**1순위: Mac 개발자/디자이너**
- 하루 종일 Chrome, Slack, IDE, Figma 사이를 오감
- "어디서 봤는데..." 가 일상
- 프라이버시에 민감 (코드, 사내 정보)
- AI 제품에 거부감 없음

**2순위: 지식 노동자 (PM, 컨설턴트, 리서처)**
- 문서, 회의, 리서치 자료가 많음
- Notion/메모 정리에 지침
- "내가 분명 정리했는데 어디에..."

**3순위: 학생/대학원생**
- 논문, 강의 자료, 참고 자료 관리
- 예산 제한적 → 무료 티어 중요

## 2. 비즈니스 모델

### 가격 구조

> 갱신(2026-08-31): 키가 어디에 있느냐로 플랜을 구분한다. BYOK/Free/Pro의 3-티어 구조와
> 서버·배포 상세는 `monetization-architecture.md` 참고.

#### Campsis Free (₩0)
- 로컬 캡처 + 로컬 임베딩·검색 (bge-m3)
- 제작자 키 기반 **제한 모델**로 답변 생성 (프록시 서버 경유, 사용량 쿼터)
- Quick Note + 파일 업로드 (PDF / MD / 이미지)
- 무제한 저장
- 로그인 필요 (남용 방지)

#### Campsis BYOK (₩0, 자기 키 사용)
- Free의 모든 기능
- **사용자 본인 OpenAI 키**로 고급 모델 답변 (앱이 직접 호출, 서버 미경유)
- 로그인 불필요, 사용량 제한 없음 (비용은 사용자 부담)
- 개발자/파워유저 대상

#### Campsis Pro (₩9,900/월, 연간 ₩7,900/월)
- Free의 모든 기능
- 제작자 키 기반 **고급 클라우드 AI (GPT-5.6 Luna)** — 넉넉한 한도
- 고급 내보내기 (Obsidian, Markdown)
- 우선 이메일 지원
- 로그인 + 결제 필요

#### Campsis Pro+ (₩19,900/월, 연간 ₩15,900/월)
- Pro의 모든 기능
- Mac ↔ iPhone 동기화
- 다중 Mac 동기화
- 팀 공유 (선택한 기억을 팀원과 공유)
- API 접근

### 가격 책정 근거

경쟁사 대비 절반 이하 가격. 무료 티어가 핵심 기능 완비.
"유료는 더 편한 경험" 포지셔닝.

### 무료 티어 정책

> 갱신(2026-08-31): 생성이 클라우드로 이동하면서 Free는 **제작자 키 + 쿼터** 방식이 되었다.
> 캡처·임베딩·검색·저장은 로컬이라 여전히 서버 비용이 0이지만, **답변 생성은 프록시 비용이 발생**하므로
> Free에는 사용량 쿼터(예: 일/월 한도 + 제한 모델)를 둔다. 비용을 아예 지기 싫은 파워유저는 BYOK로 무제한 사용.

1. 캡처·검색·저장은 로컬이라 서버 비용 0 → 데이터가 쌓이는 경험은 무료로 충분히 제공
2. 기억 앱은 데이터가 쌓여야 가치 → 저장/검색은 제한하지 않음
3. 답변 생성만 쿼터로 통제 → 충분히 써보되, 더 나은 경험은 Pro/BYOK로 유도

## 3. 유료 전환 핵심 기능

### 기능 1: 클라우드 AI (Pro의 핵심)

**구조:**
- 질문 → 벡터 검색 → 관련 기억 선별 (여기까지 100% 로컬, bge-m3)
- 선별된 기억 조각만 Campsis Proxy(Supabase Edge Function) → **GPT-5.6 Luna** 전달 (Pro만)
- 전체 DB가 아닌 관련 조각 5~10개만 전송
- 프록시가 인증·플랜·쿼터 확인 후 제작자 키로 대리 호출 (키는 서버에만 존재)

**비용 구조:**
- GPT-5.6 Luna 기준: 사용자당 월 ~₩1,200 (사용량에 따라 변동)
- 구독료 ₩9,900 - API ₩1,200 = 마진 ₩8,700 (88%)
- BYOK 사용자는 API 비용을 직접 부담 → 마진 계산에서 제외

### 기능 2: 기기 간 동기화 (Pro+의 핵심)

**동기화 대상:**
- 메타데이터 (앱, 제목, 날짜, 요약, 주제)
- 임베딩 벡터
- 암호화된 원본 텍스트

**동기화하지 않는 것:**
- 스크린샷 원본 (용량 + 프라이버시)
- 파일 원본

**방식:** iCloud CloudKit
- 사용자의 iCloud 저장소 사용
- Campsis 서버를 안 거침
- Apple E2E 암호화 적용
- 비용 거의 0

### 자동 캡처 — 제외 결정

프라이버시 메시지와 충돌하고, Rewind와 같은 포지션이 되며, 리소스/데이터 품질 문제.
"의도적 기억"이 Campsis의 차별점.
